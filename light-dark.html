View Transitions API：把「切主题」做成一场小型演出

大多数博客的明暗切换只是一次 classList.toggle，颜色在 300ms 内生硬地插值过去。而 View Transitions API 给了我们把整页快照「撕开」的能力——从点击点荡开一个圆，新的主题像光一样漫出来。

核心思路

浏览器在 startViewTransition 回调执行前后各拍一张「照片」：旧主题一张、新主题一张。我们要做的，就是接管默认的交叉淡入，改用 clip-path: circle() 让新主题从鼠标点击处向外扩张。

const transition = document.startViewTransition(() => {
  document.documentElement.classList.toggle('dark');
});
// 等快照就绪，接管 ::view-transition-new(root)
await transition.ready;
document.documentElement.animate({
  clipPath: [
    `circle(0px at ${x}px ${y}px)`,
    `circle(${radius}px at ${x}px ${y}px)`,
  ],
}, { duration: 850, pseudoElement: '::view-transition-new(root)' });
半径不用 Math.max 取视口宽或高，而要取「点击点到四个角落的最远距离」——用勾股定理算 hypot，圆才能盖满整屏。

让它「灵动」起来的三件事

第一，缓动别用线性。cubic-bezier(.2,.9,.25,1.05) 带一点点过冲，圆在收尾处微微「弹」一下，像水面涟漪拍上岸边。第二，配一个独立的辉光圆环，比主动画更快、更淡，先行一步。第三，主题按钮本身做太阳/月亮的形变，让整个交互有首尾呼应。

对不支持 View Transitions 的浏览器，静默降级回普通的 class 切换即可——功能不丢，只是少了演出。

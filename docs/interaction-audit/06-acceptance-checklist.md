# 验收检查表（真机/桌面逐条勾选）

> 用途：合并 `p0-focus-visible` 并应用 `patches-app/` 三个补丁后，按本表逐条确认。
> 每条给出「怎么试 → 期望 → 可能的回归风险」。前置：`tools/verify-cui-interactions.sh` 输出
> 「基线匹配」（TOTAL 450 / PASSED 409）。
> 哪些条目有自动化兜底、哪些必须人工看：见 [08-coverage-matrix.md](08-coverage-matrix.md)。

## A. 字段与表单（用户最初反馈的那类问题）

- [ ] **A1 点进输入框**：点击任意输入框（登录、搜索、重命名）。期望：边框与底色立刻变成激活态（accent 边），而不是只有光标闪。
  - 风险：浅色主题下 accent 边对比度偏低 → 观感验收。
- [ ] **A2 字段悬停**：鼠标划过未聚焦输入框。期望：边框出现轻微 accent 偏移（三态中的 hover）。
- [ ] **A3 Tab 遍历字段**：连续 Tab。期望：每个字段依次获得**键盘外环**（比激活边更外一圈的光晕），且外环只在键盘操作时出现；用鼠标点击时只出现激活边、不出现外环。
- [ ] **A4 回车提交（登录）**：输入账号密码后按回车。期望：直接发起登录，等同点「登录」。
- [ ] **A5 回车提交（弹窗）**：新建合集 / 加入合集搜索 / 服务器编辑弹窗内按回车。期望：分别触发创建、搜索、保存。
- [ ] **A6 打开即聚焦**：打开登录页、服务器编辑弹窗。期望：光标已在第一个输入框，可直接打字。
- [ ] **A7 关闭弹窗焦点回原位**：从某个按钮打开弹窗，Esc 关闭。期望：焦点回到那个按钮（再按回车能重新打开）。
- [ ] **A8 只读字段**：点击只读展示字段。期望：不抢焦点（不会把焦点从别处夺走）。

## B. 键盘可达性（本轮改动最大面）

- [ ] **B1 自绘卡片可 Tab**：在首页/详情页连续 Tab。期望：卡片、图标钮（下载/收藏/编辑）、列表行都进入焦点顺序，并有外环。
  - 风险：`ClickArea` 改为 `FocusTarget` 包裹后，40+ 处布局是否与原来一致（尤其撑满宽度的整行点击区）。
- [ ] **B2 Enter/Space 激活**：对任一卡片/图标钮按 Enter 或 Space。期望：等同点击（打开详情、触发下载等）。
- [ ] **B3 焦点滚入视野**：在长列表/书架里一直 Tab 到屏幕外的项。期望：容器自动滚动让它露出来。
- [ ] **B4 横排滚动**：书架横排（LazyRow）聚焦后按 Left/Right/PageUp/PageDown/Home/End。期望：按页/按项滚动。
- [ ] **B5 分页/面包屑/步骤条/标签云**：Tab 到这些控件，用方向键移动、Enter/Space 激活。期望：全部可用。

## C. 弹层与提示

- [ ] **C1 Toast 关闭**：连续触发多条提示后点击其中一条。期望：该条消失，且点击不穿透到底层控件。
- [ ] **C2 Toast 悬停**：鼠标停在提示条上。期望：自动消失计时暂停，移开继续。
- [ ] **C3 Tooltip 键盘**：Tab 到带提示的图标。期望：提示立即出现（不必等 500ms）。
- [ ] **C4 菜单键/F10**：按 Menu 键或 F10。期望：菜单栏被唤起（聚焦并展开）；右键上下文菜单同样可键盘唤起。
  - 风险：真机上 F10 可能被系统占用 → 需实测。

## D. 阅读器

- [ ] **D1 dock 键盘翻页**：Tab 到阅读器底部胶囊，按 Left/Right、PageUp/PageDown、Home/End。期望：翻一页/翻十页/到首末页，页码滑条同步。
  - 风险：焦点环画在页码滑条外圈，是否压住相邻 lane tab。
- [ ] **D2 长按/连发**：按住方向键不放。期望：连续翻页（若未连发，属已知缺口——需 L 层 `repeat` 字段，见 03-app-wiring-plan.md E 项）。
- [ ] **D3 页内翻滚**：PgUp/PgDn 在 html 页内翻滚，非 html 页不误触。

## E. 视觉与手感细节

- [ ] **E1 实心按钮**：Primary/Danger 按钮按下变深、悬停变亮。
- [ ] **E2 开关/单选/复选/滑块悬停**：鼠标划过有轻微 accent 偏移；滑块旋钮悬停变大。
- [ ] **E3 列表/表格行悬停**：整行有底色变化。
- [ ] **E4 中文双击选词**：双击中文句子里的词。期望：不会把全角逗号/句号一起选中；日文假名/汉字各自成词。
- [ ] **E5 富文本链接**：若界面中出现 `RichSpan.link`（当前应用未使用，供后续接入）。期望：accent 色 + 下划线、手型、可点击。

## F. 系统级

- [ ] **F1 深浅主题各走一遍 A1/A3/B1**：两套主题下焦点环与激活边的对比度都足够。
- [ ] **F2 高 DPI / 不同窗口尺寸**：焦点环 1.6px、外扩 2px 在不同缩放下仍清晰。
- [ ] **F3 输入法（IME）**：中文输入法候选框位置随光标（既有测试 `focusedCaretReportsImeAnchor` 覆盖桌面；真机需复验）。
- [ ] **F4 关闭再打开**：应用重启后焦点状态正常（无焦点残留环）。

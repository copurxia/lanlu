# lgpu 颜色管线与主题验证

UI 先绘制到 `Rgba8Unorm` 离屏目标，在 gamma 空间完成混合，再经 blit 转线性写入
sRGB 交换链。硬件编码还原后，采样值与设计稿的 sRGB 值一致。

## 真机结果

设备：HUAWEI MOR-M1，PC 模式，density 1.9，窗口 2090×1394。

| 主题 | 采样点 | 实测 | 设计值 |
|---|---|---|---|
| 深色 | 页面底 | `(11,11,13)` | `0B0B0D` |
| 深色 | 面板 | `(22,22,26)` | `16161A` |
| 浅色 | 页面底 | `(248,248,250)` | `F8F8FA` |
| 浅色 | 面板 | `(255,255,255)` | `FFFFFF` |

两套主题均逐字节一致。浅色与深色可通过 `LANLU_FORCE_THEME=light|dark` 启动，
便于自动化截图；该变量同时作用于启动 `Theme` 和 `AppModel.isLight()` 的调色板选择。

# LWP 验证纪律（从 102 轮实践里总结的硬规则）

这份文档只写**被实际踩过、且代价明显**的规则。每条都附真实轮次。

## 1. 否定结论必须先有"执行证据"

说"某功能没工作"之前，必须能指出**它该出现的那条日志/消息确实没出现**，
而不是"我没看到"。

- 第 83 轮：我说"引擎没发 `set_cursor`" → 实际发了，是我看的是被新实例覆盖的 hilog 窗口；
- 第 87 轮：我说"IME 没 attach" → 实际一直 attach 成功。
- 正确做法：看 `.lwtrace`（协议层证据）或 UI 侧 `console.info`；
  **C 侧的 `LOGI_LWP` 在真机上报不到 hilog，不能作为"有没有执行"的依据**。

## 2. "没反应"先做正对照（同一会话内）

- 第 86 轮：uitest 用**屏幕坐标**，窗口有 (515,292) 偏移 → 我一直点在窗口外；
- 第 101/102 轮：拖动起点 (3100,400) 在窗口外 → 误判"系统不支持拖边缩放"，
  还据此写了一轮代码（已撤）。

规则：先做一次**已知会成功**的操作证明链路通（例如内容区点击有事件、Y 轴不同位置对比），
再判断"这个位置/这个功能不工作"。

## 3. 消息类 bug 先查"有没有到达消费方"

- 第 90 轮：`LwpWindowClient.poll()` 每帧吞掉输入事件（与输入共用队列），
  导致光标/IME 锚点全部失效。一行 `probeTrace("ptr=…")` 就定位了。
- 规则：先确认数据到了消费方，再谈上层逻辑；**一行诊断胜过三轮重构**。

## 4. 静默路径必须显式打点

- 第 70 轮：默认开启后 `LANLU_LWP=="1"` 的硬编码判断失效 → 帧 tick 与 system.info 静默停摆；
- 第 70 轮：泵里插了重复的 if/else-if 分支 → 后面的分支永不执行。

规则：新增的"看起来会执行"的分支，先用一行日志证明它执行了，再写业务逻辑。

## 5. 测试基建要防"假通过/假失败"

- `Mutex::lock().unwrap()` 的 poison 会让一个失败伪装成全线崩溃（第 76 轮）；
- 并行测试共享 `WAYLAND_DISPLAY` 会互相干扰 → 加 `ENV_LOCK`（第 75 轮）；
- 需要 flush 的协议动作（如 `ack_configure`）要多走一轮 roundtrip，否则"看起来没发"（第 76、99 轮）；
- **CI 里必须 `--require`**，避免"本机跳过 → 以为在验证"（第 100 轮）。

## 6. 协议细节必须查源，不能凭记忆

同一类坑踩了 4 次：`xdg_toplevel` 请求序号、`ack_configure` 时序、`wl_output.scale` 事件号、
`PointerStyle` 成员名、`Rect` 字段名（`w/h` 不是 `width/height`）。

规则：**编号/名称一律从协议 XML、生成头文件、SDK d.ts 里查**，Grep 之后还要看上下文
（同名事件在 `wl_surface` 与 `wl_data_device` 里都有 `Enter/Leave`，第 94 轮就插错过地方）。

## 7. 回归基准要逐字节

- 启动快照 PNG sha256 `5a274b9e…` 在 M6 删除后、输入链路修复后**两次完全一致**。
- 规则：涉及输入/渲染路径的改动，都跑一次启动快照并比对 sha256 ——
  这类回归肉眼极难发现。

## 8. 结论要区分"根因"与"当前最可能解释"

第 83→85 轮我连续三次把"最可能的解释"说成"根因"，每次被下一层证据推翻。
**根因只留给已被实验证实的结论**，中间状态明确写成"当前最可能解释"。

## 9. 文档里的数字要有守卫

`tools/check-docs-consistency.py` 会校验"当前状态类"文档里的
协议消息数/接口数、文件桥处数、以及所有相对链接是否可达。

理由：数字漂移不会让任何测试失败，但会误导下一个人（第 104 轮加此守卫）。
进度日志里的历史数字**不校验**（它们本来就该与现在不同）。

## 10. 协议消息必须有"真的在发"的证据

第 110 轮发现 `surface.attach` 定义完整、两端 API 都在，但**引擎从来没调用过** ——
检查器的 attach 计数、壳的帧统计、Wayland 上屏路径全部空转。

规则：文档里写了"必须发"的消息，必须有一条**测试或打点**证明它在发：

| 消息 | 证据 |
|---|---|
| `surface.attach` | 壳侧 `frames=` 日志 + trace 计数 |
| `lw_seat.set_cursor` | hilog `cursor shape` |
| `lw_text_input.set_cursor_rect` | hilog `ime cursor` |
| `frame.request/done` | trace 成对计数 |

同类历史：`Cursor.system`（第 81 轮）、`textInputAreaSink`（第 72 轮）都是"实现了但没人调"。
覆盖情况见 [lwp-message-coverage.md](lwp-message-coverage.md)。
